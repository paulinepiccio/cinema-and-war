# cinema-and-war
How do different national film industries portray armed conflicts ? (Analysis across 6 countries)

## 🎯 Research question

Does each country's cinema reflect its own wars, or those of others?  
This project explores how the USA, France, UK, Germany, Russia, and South Korea 
have portrayed armed conflicts in cinema from 1945 to today.

## ⚠️ Methodological scope

**Time period:** Films released since 1945 (post-WWII era).

**Conflicts covered:** Armed conflicts that occurred between 1945 and today, 
with **one notable exception**: World War II (1939-1945) is included 
because it remains the most-filmed conflict in cinema history and 
serves as a shared reference point across all 6 countries studied. 

## 🛠️ Tech stack

- **Python** (pandas, requests, matplotlib, seaborn) — via Google Colab
- **TMDB API** — film data
- **GitHub** — version control & portfolio

## 📁 Project structure

- `notebooks/` — Jupyter notebooks (collection, cleaning, analysis)
- `data/raw/` — raw data from TMDB
- `data/processed/` — cleaned datasets
- `data/conflicts.csv` — manually curated list of armed conflicts
- `outputs/figures/` — generated visualizations
